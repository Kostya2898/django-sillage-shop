Кураторський магазин нішевої парфумерії. Фінальний проєкт курсу Django.

---

## Що заповнити перед здачею

- [ ] Опис проєкту — 2–3 абзаци: що це, для кого, чим відрізняється
- [ ] Скриншоти: головна, каталог, картка товару, кошик, checkout
- [ ] Стек і версії
- [ ] Встановлення й запуск (Windows / Linux)
- [ ] Наповнення демо-даними — `manage.py seed_demo`
- [ ] Змінні оточення — `.env.example` з поясненням кожної
- [ ] Структура застосунків — за що відповідає кожен
- [ ] Реалізований функціонал за уроками 1–4
- [ ] Запуск тестів і поточне покриття
- [ ] Деплой
- [ ] Відомі обмеження — зокрема те, що платіжний шлюз є **моком** і чому його
      не можна лишати в production
